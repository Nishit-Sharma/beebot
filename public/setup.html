Troubleshooting and evidence

If Connections reports unreviewed or changed global guidance, review ~/.codex/AGENTS.md yourself, then explicitly run npm run review-guidance -- --acknowledge only if you approve it. This is separate from context-sharing consent. If PATH selects an older Codex without Luna, use the installed newer binary explicitly with CODEX_BIN="$HOME/.local/bin/codex" npm start; never downgrade the model.

- No processed conversation: inspect actual processed transcript/completion, not the recording indicator. Below roughly 50 words may be deleted; use the full sample. If already signed in on Watch without the phone, connectivity alone does not prove independent processing. Wait for the paired iPhone if completion cannot be verified. No guessed buttons, raw audio or Watch APIs are used.

- Bee login required/403: verify Bee Developer Mode/login. A native-thread test_user_required error is preview eligibility, not a reason to replace the public context path or buy a plan.

- No recent match: only five metadata rows are listed; use the known numeric ID or a fresh isolated demo. Never broaden to all personal data by default.

- Source too large/unprocessed: use a shorter processed demo conversation. Do not bypass bounds by exporting your whole history.

- Codex/model unavailable: inspect Connections. Keep GPT-6 Luna; do not use private tokens or silently substitute another model.

- Waiting for source: restore Bee connectivity and wait for selected refresh (up to one minute cycle, bounded reads). Changed source revokes old plans; expired approval requires new review.

- Cancel was late: distinguish completed local preparation from an actually canceled attempt; never claim canceled work was never run if evidence shows otherwise.
